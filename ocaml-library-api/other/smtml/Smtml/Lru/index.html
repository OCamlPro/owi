Module Smtml.Lru

A simple bounded hash table with least-recently-used eviction.

This is a drop-in replacement for the subset of Hashtbl.S used across the code base, with the addition of a capacity. Once the number of bindings exceeds the capacity, the least recently used binding is discarded.

A non-positive capacity disables eviction, making the table unbounded.
